20 AI Coding Tools Worth Trying

20 AI coding tools worth trying: the 4 I use every day, plus strong alternatives and niche gems. One sentence each: what it is best for.

Saturday, November 21, 2026 3 minutes read · 499 words

AI coding tools have grown from autocomplete into agentic pair programming. I use four of them every day: Cursor, GitHub Copilot, Cline, and Codex. This list gathers 20 AI coding tools worth trying, graded S / A / B: S is my daily drivers, A is strong alternatives, B is niche but useful. One line each: what it’s best for. Compiled 2026-11-19.

S tier: daily drivers (4)

  • Cursor (used daily) — AI-native IDE; Agent mode plans, edits, and runs tests across the whole codebase. https://cursor.com
  • GitHub Copilot (used daily) — the most widely integrated coding assistant: inline completions, chat, and agent mode across editors and GitHub. https://github.com/features/copilot
  • Cline (used daily) — open-source autonomous coding agent that runs inside VS Code, edits files, and runs terminal commands. https://cline.bot
  • Codex (used daily) — OpenAI’s coding agent with a CLI, IDE extension, and cloud mode; strong at large refactors and PR review. https://chatgpt.com/codex

A tier: strong alternatives (10)

  • Claude Code — Anthropic’s terminal-first agentic coding tool, with deep understanding of your codebase. https://claude.com/product/claude-code
  • Devin — autonomous software engineer in the cloud; hand it a task and it works through to a mergeable PR. https://devin.ai
  • Zed — fast, Rust-based editor with a built-in AI assistant and agent mode. https://zed.dev
  • Augment Code — AI assistant built for large codebases, with strong context retrieval. https://www.augmentcode.com
  • Trae — ByteDance’s AI-native IDE; its TraeCode agent plans and builds for you. https://www.trae.ai
  • JetBrains AI — AI assistant built into IntelliJ, PyCharm, GoLand, and the rest of the JetBrains IDEs. https://www.jetbrains.com/ai/
  • Amazon Q Developer — AWS’s coding assistant, strongest inside AWS workflows and legacy modernization. https://aws.amazon.com/q/developer/
  • Gemini Code Assist — Google’s coding assistant for IDEs and the terminal, with a generous free tier for individuals. https://codeassist.google
  • Continue — open-source AI code assistant; bring your own model, run it locally or in the cloud. https://www.continue.dev
  • Aider — terminal pair-programming tool that edits code directly in your local git repo. https://aider.chat

B tier: niche but useful (6)

  • Sourcegraph Cody — AI assistant with whole-codebase search; best for finding and understanding code in large repos. https://sourcegraph.com/cody
  • Replit Agent — describe an idea in plain language and it builds and hosts the app in the browser. https://replit.com
  • v0 — Vercel’s text-to-UI generator; a prompt in, a React + Tailwind component out. https://v0.app
  • Bolt — browser-based full-stack app builder from a prompt; working prototypes in minutes. https://bolt.new
  • Lovable — prompt-to-product builder with hosting, auth, and payments built in; good for shipping a small product fast. https://lovable.dev
  • Warp — AI-powered terminal with an Agent CLI for running coding agents from your shell. https://www.warp.dev

How to choose

Start with where you code: if you live in an IDE, one of the four S-tier tools is enough; if you live in the terminal, Claude Code, Aider, or Warp fit better; if you want to build a product from zero, Replit, v0, Bolt, and Lovable do it in the browser. You don’t need many tools — one daily driver and one backup is enough.
