值得一试的 20 个 AI 编程工具

20 个值得一试的 AI 编程工具：每天在用的主力 4 个，加上强力替代和小众好物。每个只写一句话：它最适合干什么。

AI 编程工具已经从"自动补全"变成了"结对编程的 Agent"。我每天在用的有 4 个：Cursor、GitHub Copilot、Cline、Codex。这篇整理了 20 个值得一试的 AI 编程工具，按 S / A / B 三级：S 是每天在用的主力，A 是强力替代，B 是小众但有用。每个只写一句话：它最适合干什么。整理日期：2026-11-19。

S 级：每天在用的主力（4 个）

  • Cursor（每天在用）——AI 原生 IDE，Agent 模式可以在整个代码库里规划、改代码、跑测试。https://cursor.com
  • GitHub Copilot（每天在用）——覆盖面最广的编程助手，行内补全、对话、Agent 模式，编辑器和 GitHub 全打通。https://github.com/features/copilot
  • Cline（每天在用）——开源的自主编程 Agent，跑在 VS Code 里，能改文件、跑终端命令。https://cline.bot
  • Codex（每天在用）——OpenAI 的编程 Agent，有 CLI、IDE 插件和云端模式，擅长大型重构和 PR 审查。https://chatgpt.com/codex

A 级：值得一试的强力替代（10 个）

  • Claude Code——Anthropic 的终端优先编程 Agent，对代码库理解很深。https://claude.com/product/claude-code
  • Devin——云端自主软件工程师，给它一个任务，它能一路做到可合并的 PR。https://devin.ai
  • Zed——Rust 写的高速编辑器，内置 AI 助手和 Agent 模式。https://zed.dev
  • Augment Code——为大型代码库设计的 AI 助手，上下文检索能力强。https://www.augmentcode.com
  • Trae——字节跳动的 AI 原生 IDE，TraeCode Agent 可以规划并动手搭建。https://www.trae.ai
  • JetBrains AI——内嵌在 IntelliJ、PyCharm、GoLand 等 IDE 里的 AI 助手。https://www.jetbrains.com/ai/
  • Amazon Q Developer——AWS 的编程助手，在 AWS 工作流和老代码现代化上最强。https://aws.amazon.com/q/developer/
  • Gemini Code Assist——Google 的编程助手，支持 IDE 和终端，个人免费版额度大方。https://codeassist.google
  • Continue——开源 AI 编程助手，可以自己接模型，本地或云端都能跑。https://www.continue.dev
  • Aider——终端结对编程工具，直接在本地 Git 仓库里改代码。https://aider.chat

B 级：小众但有用（6 个）

  • Sourcegraph Cody——带全库搜索的 AI 助手，最适合在大型代码库里找代码、理解代码。https://sourcegraph.com/cody
  • Replit Agent——用一句话描述想法，它在浏览器里把应用做出来并托管上线。https://replit.com
  • v0——Vercel 的文字生成 UI 工具，一句话生成 React + Tailwind 组件。https://v0.app
  • Bolt——浏览器里的全栈应用生成器，一句话做出可运行的原型。https://bolt.new
  • Lovable——一句话做产品，托管、登录、支付都自带，适合快速上线小产品。https://lovable.dev
  • Warp——AI 终端 + Agent CLI，在命令行里跑编程 Agent。https://www.warp.dev

怎么选

先看你在哪里写代码：整天在 IDE 里，S 级 4 个里挑一个就够；常在终端里，Claude Code、Aider、Warp 更顺手；想从零做一个产品出来，Replit、v0、Bolt、Lovable 直接在浏览器里搞定。工具不用多，一个主力加一个备用，够用了。
