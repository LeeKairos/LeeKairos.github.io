表结构文档生成

粘贴 MySQL 的 CREATE TABLE 建表语句，一键解析成可读的表结构文档，并可导出为 Markdown。支持一次粘贴多张表。

全部解析在你的浏览器本地完成，DDL 不上传、不发送到任何服务器。

建表 DDL

支持反引号标识符，以及 decimal(10,2)、enum('a','b') 这类括号内带逗号的类型。

结构文档

还没有解析结果。粘贴 DDL 后点「解析生成文档」，或先点「填入示例」体验。

什么是表结构文档生成？

写文档、交接数据库、做 Code Review 时，常需要一份可读的表结构说明。这个工具把 MySQL 的 CREATE TABLE 语句解析成表格：字段、类型、是否可空、默认值、注释、主键和索引一目了然，还能导出成 Markdown。解析全在浏览器本地完成，DDL 不上传。

怎么用？

  1. 把 CREATE TABLE 语句粘贴到左边的框里，一次可以粘多张表；也可以点「填入示例」先看看效果。
  2. 点「解析生成文档」，右边的表格就是结果。
  3. 点「导出 Markdown」保存成 .md 文件，或点「复制 Markdown」直接粘到文档里。
